# 命名候选（2026-10-04）

筛选标准：两到四个字；一听就有画面；能对上「同一片天空下，有人替你走向远方」这个核心。先海外发布，所以英文名是主名，中文名用于中文界面。

## 中文候选

| 名字 | 出处 / 含义 | 为什么合适 | 顾虑 |
|---|---|---|---|
| 共此时 | 海上生明月，天涯共此时（张九龄《望月怀远》） | 旅人在天涯，却和你共享此刻的天空、天气和月亮，正是核心机制；原诗写对远方之人的思念，自带浪漫 | 三个字略拗口，偏文气 |
| 且徐行 | 何妨吟啸且徐行，一蓑烟雨任平生，也无风雨也无晴（苏轼《定风波》） | 整首词就是在雨里慢慢走、无论阴晴都从容，与「真实天气里一直走」「减压」完全贴合 | 单用「徐行」像人名，所以带「且」 |
| 步履不停 | 是枝裕和同名电影；走着走着，生活就继续了 | 温柔，年轻人熟悉，情绪价值高 | 四个字，又是电影名，商标与联想都要查 |
| 行云 | 行云流水；云在走，人也在走 | 短、好记、天空感强 | 已有不少公司在用 |
| 远方来信 | 字面 | 直接点出明信片功能 | 偏通用 |
| 候鸟 | 远行，也总会回家 | 与「回家」事件呼应 | 没体现「同一片天空」 |
| 替我看看 | 口语，「替我去看看海」 | 最有网感、最直接的情绪价值 | 更适合做 slogan |

推荐：共此时；备选：且徐行。

## 英文候选

| 名字 | 含义 | 备注 |
|---|---|---|
| Same Sky | 同一片天空 | 与「共此时」同义，推荐；上架前查 App Store 同名 |
| Faraway | 远方 | 温暖，但有同名游戏系列 |
| Yonder | 远处那边，诗意 | 已有旅行类同名 App |
| Wayfarer | 徒步旅人 | 偏硬朗 |
| Still Walking | 《步履不停》英文片名 | 电影联想 |

## Slogan 候选

- 你在这里，我在天涯，我们在同一片天空下。
- 替我看看山河湖海。
- Someone is walking the world for you, under the same sky.

## 定名前要查

1. App Store 与 Google Play 搜同名应用。
2. 中国商标网查第 9 类与第 42 类（若将来回国内上架）；海外查 USPTO / EUIPO。
3. 社交账号与域名是否可注册。
